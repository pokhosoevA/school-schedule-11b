# Расписание 11Б

Мобильное веб-приложение для просмотра школьного расписания. Работает как статический сайт и подходит для GitHub Pages.

## Что уже есть
- адаптивный интерфейс для телефона;
- переключение Пн–Сб;
- светлая и тёмная темы;
- кабинеты, номера уроков и время;
- демонстрационная отметка отмены.

## Важно перед использованием
Сейчас `schedule.js` содержит пустые дни. Заполни его проверенными данными из NEXTLER. Демонстрационная отмена действует только внутри открытой страницы и **не получает данные от школы**.

Автоматическая синхронизация отмен возможна только после проверки доступного официального API/экспорта NEXTLER или другого разрешённого источника. Не добавляй в публичный репозиторий пароли, токены или закрытые данные.

## Публикация на GitHub Pages
1. Создай новый репозиторий, например `school-schedule-11b`.
2. Загрузи все файлы из этой папки в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем сохрани.
6. Подожди завершения публикации и открой ссылку, показанную в разделе Pages.

## Как внести расписание
Открой `schedule.js`. Пример одной записи:

```js
window.SCHEDULE = {
  0: [
    { number: 1, subject: "Алгебра", room: "208Г", start: "08:30", end: "09:15" }
  ],
  1: [],
  2: [],
  3: [],
  4: [],
  5: []
};
```

Нумерация дней: `0` — понедельник, `1` — вторник, `2` — среда, `3` — четверг, `4` — пятница, `5` — суббота. Не заполняй уроки наугад.

## Добавление на главный экран iPhone
Открой опубликованный сайт в Safari → **Поделиться** → **На экран Домой**.
